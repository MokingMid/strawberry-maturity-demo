# 草莓成熟度检测与分拣 · 实验结果汇总报告

> 日期：2026-11-22
> 数据版本：`strawberry_v1`（64 图 / 183 框 / 57 独立场景）
> 说明：本报告汇总当前已完成的全部实验实测结果。所有指标均在**冻结的 test 集**上报告；受数据规模限制，**不构成泛化结论**，局限详见 §7。

---

## 1. 项目概述

**任务**：对单目 RGB 草莓图像做目标检测 + 三状态成熟度分类（`ripe` 成熟 / `half` 半熟 / `unripe` 未熟），支撑后续分拣计数。

**采用架构（两阶段）**：

```
图像 → YOLO11n（1 类检测：strawberry）→ 框外扩 12% 补方形 ROI
     → ResNet18（3 类分类：ripe/half/unripe）→ 跟踪 / 越线计数
```

**三条实验路线**：

| 路线 | 结构 | 作用 |
|---|---|---|
| A 主线 | 1 类检测 + 3 类分类（两阶段） | 检测只学"草莓在哪"，状态放第二段 |
| B 消融 | 3 类检测（YOLO 直接输出状态） | 回答"状态放进检测头是否更好" |
| C 基线 | 传统 HSV/GLCM/LBP + SVM | 回答"深度学习比传统特征提升多少" |

## 3. 实验环境与复现

- 训练/推理：YOLO11n + ResNet18，torch 2.15 / ultralytics 8.4.216
- 检测超参：120 epoch / batch 8 / AdamW lr0=0.001 / cos_lr / warmup 5 / seed 42
- 分类超参：ResNet18、224、batch 32、lr 3e-4、label smoothing 0.05、类别权重 balanced、早停 patience 8
- 置信度阈值：检测 conf=0.55（在 val 选定，test 只报告不调参）
- 划分原则：按 `scene_group` 分组，杜绝重复图跨集泄漏
- 31 个单元测试全部通过；结果已在 CPU 环境完整复现

## 5. 综合对比

| 方案 | 定位 mAP50 (test) | 定位 R | 状态准确率 / acc | half 表现 |
|---|---|---|---|---|
| **两阶段（主线）** | **0.952** | 0.885 | state 0.870 / acc 0.96 | 分类 F1=0（判成 ripe） |
| 3 类检测（消融） | 0.619 | 0.577 | — | R=0，直接漏检 |
| 传统 SVM | — | — | acc 0.92 | F1=0 |
| 传统 HSV 分割 | — | 0.295 (IoU≥0.5) | 一致率 100%* | — |

\* 传统 HSV 的"类别一致率 100%"仅针对被正确匹配的 54 个框，样本极小，不构成结论。

**核心结论**：

1. **两阶段优于 3 类检测**：定位 mAP50 0.952 vs 0.619；把稀缺的 half 隔离出检测头，避免了 half 拖垮整体定位（3 类检测里 unripe 召回也被拖到 0.731）。
2. **深度学习优于传统特征**：分类 acc 0.96 vs 0.92（SVM），且深度方案是完整检测+分类链路，传统 HSV 分割定位近乎不可用（P 0.125）。
3. **half 在所有方案下都失败**，失败方式不同：两阶段是"检测到但分类错"，3 类检测是"直接漏检"。根因一致——half 数据不足。

## 6. 失败案例分析

| 失败模式 | 位置 | 现象 | 根因 |
|---|---|---|---|
| half→ripe | 分类 test、端到端 | test 唯一 1 张 half ROI 被判 ripe；端到端 2 个 half 全判 ripe | half 训练仅 6 框且来自同一场景（006/048 重复），模型没见过独立 half 场景 |
| 检测 FN | 端到端 `image_039`（漏 2）、`image_055`（漏 1） | 低置信度小目标/遮挡漏检 | 小数据 + conf=0.55 阈值取舍 |
| 检测 FP | 端到端 `image_010`（+1）、`image_032`（+1） | 多检 2 框 | 粘连果实/背景误检 |
| unripe 误判 | 端到端 unripe state acc 0.89 | 12 个 unripe 错 1 个 | 分类器偶发错误 |
| 整图 state_acc 0 | `image_056`（2 框全错） | 该图正是 half 图 | half 数据稀缺 |
| 传统 HSV 叶片误检 | `image_039`（真值 5 → 输出 13） | 黄绿掩码把叶片算作未熟果 | 颜色阈值无法区分叶片与绿果 |

## 7. 局限（报告中必须写清）

1. **half 不可用**：11 框 / 3 场景，test 仅 1 张 half ROI、2 个 half 框；**half F1=0 / R=0**，不能声称 half 分类或检测可用。
2. **test 集太小且都是网络图**：9 图 / 26 框，带水印、来源不明；mAP50 0.952、acc 0.96 **不能当手机实拍泛化结论**。
3. **无自采测试集**：域偏移未量化。
4. **分类器 val 只有 30 张、best@ep1**：val F1=1.0 不能当泛化证据。
5. **41/168 张 ROI 与邻框重叠**：首轮保留，未做过滤对照。
6. 对照实验仅 CPU 环境复现，推理速度（检测约 40 ms/图）不代表 GPU（原机 4060 约 3–5 ms/图）。

## 9. 下一步（按优先级）

1. **补采 half**：≥10 场景 / ≥30 框，重训分类器与划分——half 能否可用的前提。
2. **自采测试集**：50–100 张手机俯拍，单独评测，验证 0.952 是否真实。
3. **视频 Demo**：检测 → 分类 → 跟踪 → 越线计数（管线已就绪，缺真实视频）。
4. **ROI overlap 过滤对照**：41 张邻框重叠样本，对比"过滤 vs 不过滤"。
5. 将本报告数字与数据卡、split 清单做最终一致性核对。
