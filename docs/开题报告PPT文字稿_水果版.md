# 开题报告 PPT 文字稿（水果版）

> **用途**：直接用于制作开题 PPT 的页面文字与讲稿  
> **统一口径**：页面只写“水果 / 目标水果 / 多种水果”，**不出现具体水果种类**  
> **结构**：13 页主讲 + 6 页备用  
> **时长**：约 9:30–10:00  
> **说明**：本文件是“做 PPT 时用的文字”，不是某一版成品的截图说明。

---

## 0. 统一口径

### 0.1 页面写法

| 位置 | 统一写法 | 不要写 |
|---|---|---|
| 题目 | 基于单目 RGB 的水果成熟度检测与分拣 | 某一种水果的名称 |
| 范围 | 多种水果 / 目标水果 | “2 种水果”及具体水果名 |
| 检测 | 水果检测 / 水果目标检测 | 具体物种分类 |
| 分类 | 4 种外观状态 | 具体品种的成熟度差异 |
| 数据 | 公开水果成熟度数据集 / 公开水果检测数据集 | 带物种描述的数据集全名 |
| Demo | 水果 · 成熟 0.92 | 具体水果名 + 状态 |
| 商用案例 | 商用水果分选线 | 某一种水果的分选线 |

### 0.2 两条规则

1. **页面文字**只放关键词、数字、短句；完整句子放讲稿。
2. 如果老师追问“具体是哪几种水果”，**口头回答**，不要写进页面；回答口径见第 6 节。

**页面眉题**：01 / 背景

**页面标题**：成熟度决定价格，也决定损耗

**右侧要点**：

- 人工分选标准不一，无法逐果追溯

**结论条**：用单目 RGB 做水果外观成熟度的自动分级

**页脚**：数据来源：[1] FAO 2019；[2] FAO 2023。开题阶段使用区间描述，最终数字以报告为准。

### 第 3 页｜研究现状

**页面眉题**：02 / 现状

**页面标题**：三条路线，各有一块短板

**三列内容**：

| 路线 | 做法 | 优点 | 局限 | 代表 |
|---|---|---|---|---|
| 传统视觉 | 颜色 / 纹理 / 光谱 + 阈值 / SVM | 可解释、成本低 | 怕光照、泛化弱 | 颜色直方图 / 阈值 |
| 深度学习 | YOLO / CNN 检测与分类 | 精度高、可端到端 | 依赖数据、调参多 | YOLO / ResNet |
| 商用系统 | 近红外 / 多光谱 + 多传感器 | 0.5 s 测 12 项指标 | 成本高、体积大 | 近红外分选线 |

**结论条**：我们的位置：低成本单目 RGB + 完整链路原型，不追求产线指标。

**页脚**：参考：[4] 水果分级技术综述；[7] 商用水果分选线公开报道。商用案例数字来自公开报道。

**讲稿要点**：

> 现有做法有三类。传统视觉用颜色、纹理加分类器，可解释但怕光照；深度学习用 CNN 和 YOLO，精度高但依赖数据；商用线用近红外和多传感器，0.5 秒能测 12 项指标，但成本高、体积大。我们的定位是低成本单目 RGB 的完整链路原型，不追求产线指标。

**配图/版式**：三列卡片，每列“做法 / 优点 / 局限 / 代表”四行；底部一条深绿色定位条。

**底部小字**：左栏“所有输出都在这个范围内”；右栏“这些不是不能做，而是四周内不做”。

**讲稿要点**：

> 我们把问题限定清楚：输入是单目 RGB 图像或视频，输出是水果位置和四种外观状态；只做少数目标水果，只做外观成熟度，不测糖度硬度，不做多品种通用，也不做硬件分拣。范围收窄，是为了四周内交付一个完整、可复现的系统。

### 第 5 页｜技术路线

**页面眉题**：04 / 方法

**页面标题**：两阶段：先定位，再判成熟度

**主流程（从左到右）**：

1. 视频 / 图像
2. 水果检测（YOLO）—— 位置 + 边界框
3. ROI 裁剪
4. 成熟度分类 —— 4 状态
5. 跟踪
6. 分拣线 / 料筐 / 日志

**对照分支**：HSV 颜色矩 + GLCM / LBP + SVM

**离线训练（从左到右）**：

公开数据 + 自采数据 → 统一标签 → 按场次划分 → 训练 / 评估

**三条理由**：

- 分类数据可复用
- 小样本更稳
- 方便做消融

**页脚**：两阶段 = 检测定位 + 分类判熟；端到端单模型作为对比实验。

**讲稿要点**：

> 技术路线是两阶段：YOLO 先检测水果的位置，裁剪出果实区域后送分类器判成熟度，再用跟踪和虚拟分拣线做计数。下面这条是传统特征基线，用来做对照。两阶段的好处是分类数据可以复用，小样本下更稳，也方便做消融。

**配图/版式**：一条六盒主流程，箭头标注“检测 / 裁剪 / 分类 / 跟踪 / 触发”；下方一条四盒离线训练流程；底部三条浅绿理由条。

### 第 7 页｜标签体系

**页面眉题**：06 / 标注

**页面标题**：四种状态，先定边界再标注

**状态表**：

| 状态 | 外观判据 | 标注处理 |
|---|---|---|
| 未熟 | 无明显转色、质地硬 | 保留 |
| 成熟 | 达到目标色、适度软 | 保留 |
| 过熟 | 颜色过深 / 起皱 / 过软，无霉斑渗液 | 保留 |
| 损坏 | 霉斑 / 渗液 / 裂口 / 明显腐烂 | 保留，报告中说明含机械损伤 |

**右侧标注规范 v1**：

- 每状态 3 张参考图
- 两人各标 50 张
- 一致率目标 ≥ 80%
- 低于 70% 的类别重新定义
- 边界样本双人复核

**底部四条规则**：

- 过熟看颜色 / 质地
- 损坏看霉斑 / 渗液 / 裂口
- 遮挡 > 50% 不标
- 一颗水果一个状态

**页脚**：边界样本（过熟 vs 损坏）放备用页；标注前先对齐 10 张困难样本。

**讲稿要点**：

> 四种状态的定义写在规范里：未熟、成熟、过熟、损坏。最容易混的是过熟和损坏，我们用霉斑、渗液、明显破损作为损坏的判据；遮挡超过一半不标。每个状态配三张参考图，两个人先各标 50 张算一致性。

**配图/版式**：左侧四行状态表，右侧标注规范卡，底部四条规则条；不出现具体水果名称。

### 第 8 页｜检测与分类模型

**页面眉题**：07 / 模型

**页面标题**：轻量模型 + 传统基线，做得出也说得清

**左侧流程（从上到下）**：

1. 输入：视频 / 图像
2. 水果检测：YOLO11n
3. ROI 裁剪
4. 成熟度分类：YOLO11n-cls / ResNet18
5. 输出：4 状态 + 置信度

**右侧训练设置表**：

| 任务 | 模型 | 关键设置 |
|---|---|---|
| 检测 | YOLO11n | 640 · batch 16 · 100–150 ep |
| 分类 | YOLO11n-cls / ResNet18 | 224 · 60 ep · 迁移学习 |
| 对照 | HSV+GLCM+LBP+SVM | ROI 裁剪后分类 |

**提示条**：增强：翻转、缩放、轻度 HSV；不做大幅色相抖动——颜色就是成熟度线索。

**指标条**：mAP50 / mAP50-95 · Acc / Macro-F1 · 混淆矩阵

**页脚**：两阶段 vs 单模型：作为消融实验，不先入为主。

**讲稿要点**：

> 检测用 YOLO11n 起步，640 分辨率；分类用轻量分类网络，四类状态，224。传统基线是 HSV 颜色矩加 GLCM 纹理再加 SVM。训练时注意别做大幅色相抖动，因为颜色就是成熟度线索。评估看 mAP、宏 F1 和混淆矩阵，重点看过熟和损坏的互错。

**配图/版式**：左侧竖向五步流程，右侧训练设置表；下方一条浅黄提示条和三个指标标签。

### 第 12 页｜风险与应对

### B2｜过熟 vs 损坏

**标题**：过熟 vs 损坏：边界案例

**左栏：过熟 overripe**

- 颜色过深、起皱、整体过软
- 没有霉斑、渗液、裂口
- 仍可能有商品价值（加工 / 即食）
- 判据以“整体状态”为主

**右栏：损坏 spoiled**

- 霉斑、渗液、裂口、明显腐烂
- 局部病变或机械损伤也算
- 食品安全风险，直接剔除
- 判据以“可见缺陷”为主
- （两张参考图占位）

**底部条**：边界不清时：两人复核 → 仍不一致 → 合并类别或从数据中剔除。

### B3｜两阶段 vs 单模型

**标题**：两阶段 vs 单模型

| 维度 | 两阶段（检测 + 分类） | 单模型 |
|---|---|---|
| 数据复用 | 分类数据可直接复用 | 需要联合标注 |
| 小样本稳定性 | 较高，分类器可单独调 | 较低，类别间竞争 |
| 可扩展性 | 加水果只改检测器 | 加水果要重训全部类别 |
| 推理复杂度 | 两次前向，可批处理 | 一次前向，端到端 |
| 本项目的选择 | 主线 | 对比实验 |

**结论条**：先用两阶段保证交付，再用单模型做消融，不先入为主。

## 6. 答辩口径

### 6.1 如果老师问“具体是哪几种水果”

> 开题阶段用少量目标水果做方法验证，页面统一按“水果”表述；具体种类会在数据说明和实验记录里固定，不影响技术路线。

### 6.2 如果老师问“为什么页面不写种类”

> 开题想先讲清楚方法链路和数据流程，不把问题绑在某一种水果的品种特性上；具体种类在数据方案确定后补充到实验记录。

### 6.3 如果老师问“检测几类”

> 检测只负责定位水果，输出“水果”这一类加边界框；成熟度由第二阶段的四状态分类器完成。物种数量不进入模型输出。

### 6.4 如果老师问“换水果还能不能用”

> 检测器可以扩展到新的水果；分类器需要重新标数据训练。本次不做多品种通用，这是范围之外。
