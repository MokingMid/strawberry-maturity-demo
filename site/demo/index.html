说明

  • 完全本地推理：ONNX Runtime Web（WASM），图片不会离开你的设备。
  • 与 Python 端一致：LetterBox、YOLO 解码、NMS、ROI 裁剪、分类预处理全部逐项对齐， 已在 test 集上验证成熟度判定 17/17 与 PyTorch 相同。
  • 模型：检测器 YOLO11n（fp32，10.1 MB）· 分类器 ResNet18（int8，10.8 MB，量化后精度损失 0.4%）。
  • 需要 WebAssembly 支持的现代浏览器（Chrome / Edge / Firefox / Safari 16+）。
